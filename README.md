| 内容 | 生成方式 |
| --- | --- |
| 墙面贴图 | 圆角矩形有符号距离场算出充气鼓包，高斯高光/底部阴影做软胶质感，拼缝、铆钉、`fbm` 橡胶颗粒噪声，再叠糖果条纹／波点／星星花纹 |
| 地面贴图 | 棋盘乙烯、彩纸地毯、糖果条纹、气泡软垫，逐像素程序化生成 |
| 天空 | 512×256 全景：垂直渐变 + `fbm` 云层 + 太阳光晕 + 散落的远景气球（含球体朗伯明暗与打结） |
| 光照 | 关卡载入时烘焙光照贴图：环境光 + 串灯点光源 + 墙角 AO；墙体外墙格继承相邻空地光照；开火时叠加动态点光源 |
| 气球人角色 | Canvas 2D 参数化绘制：气球头（径向渐变乳胶 + 高光 + 打结）、躯干花纹、四肢胶囊、眼睛嘴巴；每个类型有专属配件（皇冠／墨镜／八字胡／吹镖长鼻／引信／翅膀）与 6 帧行走循环 |
| 武器 | 矢量路径现场绘制，第一人称透视：近宽远窄的透视管体、金属渐变机匣、气球气室、旋转彩带弹鼓 |
| 玩家双手 | 乳胶手套：四指 + 拇指 + 掌部径向渐变 |
| 地图 | 构建器 API（`room` / `hall` / `pillar` / 递归回溯迷宫）程序化搭建 |
| 战斗特效 | 彩纸碎片（可旋转矩形，带空气阻力与地面反弹）、乳胶碎块、烟雾、弹孔贴花、屏幕震动、动态点光源、枪口星芒、命中标记 |
| 音效 | WebAudio 实时合成：气球爆裂是正弦扫频下滑 + 带通噪声，枪声是滤波噪声包络，爆炸是低频轰鸣 + 噪声，脚步是低通噪声短脉冲，带 3D 声像（`StereoPannerNode`） |

## 引擎

手写光线投射（raycasting）引擎，无任何第三方库：

1. **天空** —— 按相机角度逐像素采样全景贴图，带视差
2. **地面** —— 逐像素纹理投射，2×2 像素块分块，烘焙光照双线性采样，材质随格子切换
3. **墙体** —— DDA 步进，按面区分侧向明暗，烘焙光照 + 动态光源，指数距离雾
4. **地面贴花** —— 透视压扁的地面精灵
5. **精灵** —— 垂直 billboard，带逐列 z-buffer 遮挡测试、加法混合、受击白闪
6. **后期** —— 暗角、受击红闪、枪口泛光、轻微抖动

内部渲染分辨率按整数倍缩放（480×270 ~ 640×360），保证像素风格的锐利；
在 1920×1080 下重负载（16 敌 + 70 气球 + 460 粒子 + 500 精灵）纯 CPU 渲染约 11 ms。

## 目录

```
balloon-fps/
├── index.html              ← GitHub Pages 入口（= 单文件成品）
├── dist/balloon-fps.html   ← 可下载的单文件成品，双击即玩
├── dev.html                ← 开发版入口（引用 src/，需本地起服务）
├── src/
│   ├── core.js             数学 / 随机 / 噪声 / 颜色 / 输入 / WebAudio 合成 / 音乐
│   ├── art.js              程序化贴图、天空、角色精灵、武器视图模型
│   ├── world.js            地图构建器、关卡、敌人 AI、气球物理、弹道、粒子
│   ├── render.js           光线投射渲染器
│   └── game.js             玩家、武器、波次、HUD、状态机
└── build.js                把 src/ 内联进单文件
```

改动源码后执行 `node build.js` 重新生成单文件版本。

## 兼容性

需要支持 WebGL 无关，仅用 Canvas 2D + WebAudio，Chrome / Edge / Firefox / Safari 均可。
建议桌面浏览器 + 独立显卡；移动端未适配触屏操作。
